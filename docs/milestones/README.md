## 진행 규칙

- **상태 값**: `대기` → `진행 중` → `완료`. 단계의 모든 완료 조건이 체크되면 `완료`로 바꾼다.
- **작업 체크**: 각 단계 문서의 작업 체크박스는 해당 작업을 구현한 PR에서 함께 체크한다.
- **실기기 항목**: `(실기기)` 표시가 붙은 항목은 개발자가 실제 기기에서 확인했다고 알려준 뒤에만 체크한다. 에이전트가 CI 통과만으로 체크하지 않는다.
- **미결정 항목**: 단계에서 확정한 값은 [TECH_SPEC §15](../TECH_SPEC.md#15-미결정-항목)의 상태와 기록 위치에 반영한다.
- **PR 단위**: 작업 한 줄이 대략 PR 하나다. 너무 크면 나눠도 된다. PR 본문의 관련 문서 항목에 단계(예: `M3`)를 함께 적는다.
- **범위 변경**: 작업을 추가·삭제하거나 순서를 바꾸면 이 문서와 해당 단계 문서를 같은 PR에서 갱신한다.

## 단계 문서 형식

각 단계 문서는 다음 구조를 따른다.

- **목표**: 이 단계가 끝나면 무엇이 가능한가
- **작업**: PR 단위 체크리스트
- **완료 조건**: 검증 가능한 체크리스트. 실기기 확인은 `(실기기)` 표시
- **결정할 항목**: 이 단계에서 확정하는 TECH_SPEC §15 번호
