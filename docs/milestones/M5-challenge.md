## 목표

실물과 거울을 번갈아 보여주는 챌린지 모드를 광과민성 경고와 함께 제공한다. 얼굴 박스도 함께 올바르게 반전된다.

## 작업

- [ ] `intervals.ts`: PRD F2 범위 클램프·단위 정규화·기본값, 단위 테스트 (§11.1)
- [ ] `useChallengeFlip`: UI 스레드 반복 토글, 간격 변경 시 재시작, 종료 시 원래 모드 값 복원 (§4.3)
- [ ] `PhotosensitivityDialog`: 매 진입 표시, 다시 보지 않기 저장, 취소 시 미시작. 한/영 문구 (§15 #13)
- [ ] 챌린지 UI: 진입/종료 버튼, 속도 슬라이더, `챌린지` 라벨 고정, 셔터·수동 모드 전환 비활성화
- [ ] 종료 조건: 앱 비활성화·화면 잠금·카메라 중단 시 종료, 자동 재개 없음

## 완료 조건

- [ ] CI: `intervals.ts` 단위 테스트 통과
- [ ] (실기기) 실물·거울 양쪽에서 시작 후 첫 간격이 지나 반전되고, 종료 시 원래 모드로 돌아간다
- [ ] (실기기) 챌린지 중 얼굴 박스가 표시 이미지 기준으로 올바른 위치에 있다
- [ ] (실기기) 경고가 매 진입 시 표시되고, 취소하면 시작하지 않으며, 다시 보지 않기가 재실행 후 유지된다
- [ ] (실기기) 저장 중에 챌린지를 시작해도 저장 결과가 촬영 시점 모드와 같다
- [ ] (실기기) 다른 앱 이동 후 돌아오면 챌린지가 꺼져 있다
- [ ] (실기기) 간격 정확도를 측정한다 (§15 #8)
