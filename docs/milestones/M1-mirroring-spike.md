## 목표

앱의 핵심인 반전 처리 가정을 S23 실기기에서 먼저 검증한다. 결과에 따라 M2~M4의 설계를 확정하거나 수정한다.

## 작업

- [ ] 검증 화면: M0 앱에 임시 개발용 화면을 추가한다. 전면 카메라 프리뷰(`mirrorMode: 'off'`), `scaleX` 컨테이너 토글, 얼굴 인식 원시 좌표 박스, 촬영 버튼(로컬 파일 확인)을 둔다
- [ ] 좌우·경계 판별 방법 정의: 글자와 가장자리 표식을 촬영해 방향과 프레임 경계를 비교하는 절차
- [ ] §4.4 가정 1~4와 추가 확인 항목 검증
- [ ] `docs/SPIKE_MIRRORING.md` 작성: 항목별 방법·결과(통과/실패)·근거 스크린샷·설계 영향
- [ ] 결과를 TECH_SPEC §4~§7에 반영한다. 가정이 틀려 설계가 바뀌면 PR 본문에 명시하고 개발자 확인을 받는다
- [ ] 재사용할 코드(카메라 설정, 좌표 변환 초안)는 정식 위치로 옮기고 나머지 검증 코드와 임시 화면은 제거한다
