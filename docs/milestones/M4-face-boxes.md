## 목표

온디바이스 얼굴 인식으로 실물/거울 모드 모두에서 얼굴 위치에 박스를 부드럽게 표시하되, 프리뷰 프레임률을 해치지 않는다.

- [ ] `useFaceDetection`: `fast` 모드, 작업 중첩 금지, 늦은 결과 무시, 토글 OFF 시 인식 중지 (§6)
- [ ] `FaceBoxes`: 여러 얼굴 표시, 떨림 감소 보간, 미감지 시 숨김
- [ ] 오류 처리: 안내 후 박스만 중지, 토글로 재시도, 영구 설정은 덮어쓰지 않음
