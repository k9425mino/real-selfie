## 목표

앱을 켜면 바로 비반전 프리뷰가 보이고, 실물/거울 전환과 격자를 쓸 수 있으며, 설정이 재실행 후에도 유지된다. 거울 대신 매일 쓸 수 있는 상태.

## 작업

- [ ] 설정 저장소: `storage.ts`(`settings.v1`, 손상 JSON·누락 필드 폴백)와 `SettingsContext`, 단위 테스트 (§9, §11.1)
- [ ] 카메라 권한 흐름: 요청, 거부 안내 화면, `Linking.openSettings()`, 설정 복귀 시 재확인 (§8)
- [ ] `useCameraSetup`: 전면 카메라, 3:4 포맷, 프레임률 선택, `isActive` (§5)
- [ ] `MirrorContainer`와 실물/거울 토글, 모드 라벨 (§4.2)
- [ ] 화면 레이아웃: 3:4 프리뷰, 어두운 테마 고정, safe area, 작은 화면·큰 글자에서 모든 버튼 표시, 하단 조작 영역 (PRD §5)
- [ ] `GridOverlay`와 격자 토글 (F3)
- [ ] 카메라 중단 시 자동 복구와 재시도 버튼, 화면 켜짐 유지 (§5)
- [ ] 이 단계 버튼의 접근성 라벨
